# 双模式卡牌可见性规则

本规则取代旧版“机器人猜牌前先私密登记”及“机器人随机生成牌值”的开局方式。HTTP 字段与 protocol_version=1.0 保持兼容，改变的是任务顺序。

| 模式 | 谁猜 | 开局 | 游戏结束核验 |
|---|---|---|---|
| player_hides | 机器人猜牌 | 玩家藏好牌，不给机器人看；C 无秘密数字，不发 B 登记任务 | 锁定最终猜测后，玩家把牌面朝摄像头；B 识别，A 复述确认，C 判定 |
| robot_hides | 玩家猜牌 | 玩家把牌背朝自己、牌面朝机器人；B 识别并确认后 C 私密记住该值，之后开始提问 | 玩家最终提交后，与机器人记住的值比较；不要求再揭牌 |

## A 李馨瑶

机器人猜牌：开局播报藏好牌，不提示登记；最终猜测确认后等待 B 揭牌结果，再公开复述牌值并确认。最终猜测与揭牌确认是两个独立步骤。

玩家猜牌：机器人记住牌前不开放问题窗口；开局确认后只播“已经记住”，不要读出牌值。

## B 刘九尔

- `vision.capture/registration` 和 `registration.confirm` 现在仅出现在 robot_hides，即玩家猜牌模式的开局。
- `vision.capture/reveal` 仅出现在 player_hides 的最终猜测锁定后。
- 现有采集、JPEG 上传、候选确认字段不变，以 C 发出的命令为准，不自行在机器人猜牌开局采集牌面。
- 真实卡牌的数字面及识别标记都应朝向机器人；玩家猜牌时避免被玩家提前看到。软件无法验证玩家是否偷看。

## C 刘杰

player_hides 在最终揭牌确认前 secret 始终为空，不能预先核验玩家答案真假。最终揭牌确认后，以该牌作为本局真值，核验历史中假话是否超过一次，然后判定猜测是否正确。

不再把揭牌与“开局登记牌”比较，因此不再使用两次登记/揭牌不一致规则。识别错误可取消后重新采集；无有效揭牌时不判胜负。软件无法独立证明玩家中途未换牌，需游戏规则约束。

robot_hides 不再使用随机生成的数字作为正式牌值；必须收到 B 对实际卡牌的有效识别和确认后才能开始。真实值不进入公开状态，也不由 A 读出。

## D 吴零

猜牌 strategy.decide/guess_next 的输入不变，仍只有公开历史和剩余次数，开局无需知道牌值。藏牌 answer_question 的 secret 改为机器人开局记住的实际牌值，算法无需改动。

## 生效方式

Z 盘文件更新不会自动替换已经运行的 Python 进程。正在进行的旧局应先结束，再停止并重启裁判服务和客户端；重启后未完成旧局会归档为中断。不要在旧进程中按新规则联调。
