| 方向 | 内容与边界 |
| --- | --- |
| A → C | 结构化问题、回答、提交和控制意图；播报反馈。A 不修改计次与胜负 |
| B → C | 私密登记/揭牌结果、有效性、牌值、采集时间、证据路径；登记另需玩家确认 |
| C → D | 猜牌仅传公开历史和剩余次数；藏牌回答可传本方秘密值 |
| D → C | 提问、最终答案或回答建议，以及对应请求编号；裁判检查后提交 |
